The Building Blocks

1. Neurons (Nodes)

Think of a neuron as a simple container that holds a number. In our model, they hold numbers between 0 and 1. The input neurons get their numbers from the real world (your sliders). The other neurons calculate their numbers based on the ones before them.

2. Weights (The Connections)

When data flows from one neuron to another, it travels across a connection called a Weight. A weight is just a multiplier. If a connection has a high weight, it means "pay a lot of attention to this data." If it's low or negative, it means "ignore this data."

New Value = Input × Weight

3. Bias

Sometimes you want a neuron to activate even if the input is zero, or stay off even if the input is slightly positive. A Bias is a constant number added to the result to shift it up or down.

Value = (Input × Weight) + Bias

4. Activation Function (ReLU)

If we just multiplied and added numbers, a neural network would just be a basic linear calculator. To understand complex things, we squish the final number using a math rule. In this demo, we use ReLU (Rectified Linear Unit), which simply says:
"If the number is negative, make it 0. Otherwise, leave it alone."
